Confidentialité

Ce site ne dépose aucun cookie, n'affiche aucune publicité et ne vous demande aucune donnée pour être consulté.

Les outils

Les quatre outils (simulateur AAH, calcul de l'AEEH, date de refus implicite, calendrier de renouvellement) fonctionnent entièrement dans votre navigateur. Les informations que vous saisissez, y compris celles qui touchent à votre santé ou à votre handicap, ne sont ni envoyées à un serveur, ni enregistrées, ni mesurées. Aucun script externe n'est chargé sur ces pages. Le rappel d'agenda (.ics) est créé sur votre appareil.

Mesure d'audience

Aujourd'hui, aucune mesure d'audience n'est installée : aucun compteur, aucun outil de statistiques, aucun cookie. Si cela change un jour, cette page sera mise à jour avant, et tout outil qui en aurait besoin ne serait chargé qu'avec votre accord.

Achat du Kit dossier MDPH

Le paiement du kit est traité par Stripe, sur sa propre page : nous ne voyons pas votre numéro de carte. Stripe nous transmet votre adresse e-mail, votre nom et le montant payé, conservés pour la comptabilité et pour vous renvoyer le kit si besoin. Aucune information de santé n'est demandée. Après le paiement, la page de téléchargement garde sur votre appareil (stockage local du navigateur) l'identifiant de la commande, pour que vous puissiez y revenir ; rien n'est envoyé.

Polices de caractères

Les polices Lexend et Fraunces sont hébergées sur le site lui-même : aucun serveur tiers n'est contacté pour les afficher.

Hébergement et journaux techniques

Le site est hébergé par GitHub Pages. Comme tout hébergeur, GitHub enregistre dans ses journaux techniques l'adresse IP des visiteurs, pour la sécurité et le bon fonctionnement du service. L'éditeur du site n'a pas accès à ces journaux. Détail : déclaration de confidentialité de GitHub.

Vos droits

L'éditeur du site ne détient aucune donnée personnelle vous concernant : il n'y a rien à consulter ni à effacer de son côté. Si vous nous écrivez, votre message est conservé dans notre messagerie le temps de vous répondre. Pour toute question : contact@mes-droits-handicap.fr. Vous pouvez aussi saisir la CNIL.
