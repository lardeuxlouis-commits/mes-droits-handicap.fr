Confidentialité

Ce site ne dépose aucun cookie, n'affiche aucune publicité et ne vous demande aucune donnée pour être consulté.

Les outils

Les quatre outils (simulateur AAH, calcul de l'AEEH, date de refus implicite, calendrier de renouvellement) fonctionnent entièrement dans votre navigateur. Les informations que vous saisissez, y compris celles qui touchent à votre santé ou à votre handicap, ne sont ni envoyées à un serveur, ni enregistrées, ni mesurées. Aucun script externe n'est chargé sur ces pages. Le rappel d'agenda (.ics) est créé sur votre appareil.

Mesure d'audience

Sur les pages d'information (guides, délais), un compteur de visites sans cookie et anonyme peut être utilisé (GoatCounter) : il compte les pages vues, sans vous identifier et sans suivre vos réponses aux outils. Il n'est jamais chargé sur les pages des outils.

Polices de caractères

La police Lexend est hébergée sur le site lui-même : aucun serveur tiers n'est contacté pour l'afficher.

Vos droits

Le site ne détenant aucune donnée personnelle vous concernant, il n'y a rien à consulter ni à effacer. Pour toute question : contact@mes-droits-handicap.fr. Vous pouvez aussi saisir la CNIL.
